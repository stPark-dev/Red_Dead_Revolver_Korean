레드 데드 리볼버 한글패치 v{{VERSION}} (베타)
=================================================

PS2 북미판 Red Dead Revolver (SLUS-20500) 비공식 한글패치입니다.
원본 ISO에 차이 패치(xdelta)를 적용해 한글판 ISO를 새로 만듭니다. 원본 ISO는 바뀌지 않습니다.

※ 베타판입니다. 번역은 AI(GPT·Claude)가 초벌을 만들었고, 사람의 문장별 검수는 아직 끝나지 않았습니다.
  오역·어색한 문장·글자 넘침을 보시면 제보해 주세요.


준비물
------
- 북미판 Red Dead Revolver ISO (SLUS-20500)
  SHA1: {{SRC_SHA1}}
  (Windows에서 확인: 명령 프롬프트에서  certutil -hashfile "원본.iso" SHA1)
- 에뮬레이터 PCSX2 (또는 PS2 실기용 ISO 실행 환경. 실기는 확인하지 않았습니다)


Windows에서 적용
----------------
1. 받은 zip을 완전히 풉니다 (zip 창 안에서 바로 실행하지 마세요).
2. 원본 ISO를 「한글패치_적용.bat」 위에 끌어다 놓습니다.
   (또는 원본 ISO를 이 폴더에 넣고 「한글패치_적용.bat」을 더블클릭)
3. 「완료」가 나오면 이 폴더에 {{OUT_NAME}} 이 생깁니다.
   Windows 보안 경고가 뜨면 「추가 정보 → 실행」을 누르세요. 서명하지 않은 팬 제작 스크립트라서 뜨는 경고입니다.


Linux / macOS에서 적용
----------------------
xdelta3가 필요합니다 (Debian·Ubuntu: sudo apt install xdelta3, macOS: brew install xdelta).

    sh apply.sh "Red Dead Revolver (USA).iso"

원본과 결과의 SHA1을 모두 확인한 뒤 「완료」를 출력합니다.


다른 도구로 직접 적용
---------------------
patch/{{PATCH_FILE}} 은 표준 xdelta3(VCDIFF) 파일입니다. xdelta UI, Delta Patcher 같은 도구로도 적용할 수 있습니다.

    xdelta3 -d -s "Red Dead Revolver (USA).iso" patch/{{PATCH_FILE}} "{{OUT_NAME}}"

결과 ISO의 SHA1: {{OUT_SHA1}}


플레이할 때
-----------
- 자막은 게임 안 「설정 → 소리 설정 → 자막」을 켜야 보입니다.
- 기존 세이브(메모리 카드)를 그대로 쓸 수 있습니다.


한글화 범위
-----------
- 메뉴·HUD·튜토리얼·대사, 컷신과 동영상 자막, 일지(장 선택) 화면, 멀티플레이 설정
- 로딩 화면·게임 오버 등 그림 속 글자 일부

영어로 남는 것
--------------
- 타이틀의 「Press START」, 메모리 카드 안내, 상점·무기 선택·장 시작 메뉴 (게임 내장 무비 형식이라 아직 못 바꿈)
- 보스·동료 체력바 이름, 「COMPLETED」 도장, 캐릭터 소개 이름 그림
- 음성은 영어 원본 그대로입니다.

확인한 범위
-----------
PCSX2에서 메뉴·설정, 1장, 현상금 사냥꾼 모드 20개 장 진입, 컷신·동영상 자막, 멀티플레이 맵 26종을 확인했습니다.
스토리 모드를 처음부터 끝까지 이어서 플레이하지는 않았습니다.
